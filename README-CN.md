## 项目概述

本项目实现了一个实时视线估计系统，可以从视频流中检测人的视线方向。系统结合了：
- **人脸检测**: 使用 MediaPipe FaceMesh 检测面部关键点
- **头部姿态估计**: 使用 Perspective-n-Point (PnP) 算法估计 3D 头部方向
- **视线估计**: 使用预训练的 ResNet18 模型从归一化的面部图像预测视线角度

系统实时输出头部姿态角度（俯仰角、偏航角、翻滚角）、视线角度（俯仰角、偏航角）以及 3D 空间中的视线向量。

## 系统架构

```
视频输入 → 人脸检测 → 头部姿态估计 → 视线估计 → 可视化输出
                   ↓                  ↓                    ↓
              面部关键点          3D姿态信息              归一化图像
                                          ↓
                                   视线向量
```

## 功能特点

- **实时处理**: 高帧率处理视频帧
- **高精度人脸检测**: 使用 MediaPipe FaceMesh 进行鲁棒的面部关键点检测
- **3D 头部姿态估计**: 使用 PnP 算法计算精确的头部方向
- **基于深度学习的视线估计**: 使用在视线数据集上训练的 ResNet18 模型
- **可视化**: 绘制边界框、关键点、头部姿态坐标轴和视线向量
- **距离计算**: 计算人脸到相机的距离

## 使用方法

### 运行实时演示

```bash
python main.py
```

### 关键操作

- **退出**: 按 'q' 键退出应用程序
- **输出**: 系统向控制台打印以下信息：
  - 面部角度（俯仰角、偏航角、翻滚角），单位为度
  - 视线角度（俯仰角、偏航角），单位为度
  - 3D 空间中的视线向量
  - 到相机的距离

### 程序流程

1. **视频捕获**: 打开默认相机（索引 0）
2. **人脸检测**: 使用 MediaPipe 检测每一帧中的人脸
3. **头部姿态估计**: 使用 PnP 算法估计头部方向
4. **视线估计**: 
   - 根据头部姿态归一化人脸图像
   - 运行 ResNet18 模型预测视线角度
   - 将角度转换为 3D 视线向量
5. **可视化**: 在帧上绘制结果
6. **显示**: 在窗口中显示带注释的帧

### 文件说明

#### main.py
主脚本，协调整个视线估计管线。处理视频捕获、人脸检测、姿态估计和可视化。

#### common/face.py
定义 `Face` 类，封装所有与人脸相关的数据，包括：
- 边界框
- 2D 关键点
- 3D 头部姿态（旋转和位置）
- 视线向量和角度
- 用于视线估计的归一化图像

#### common/landmarks.py
包含用于头部姿态估计的 3D 面部关键点坐标。这些是来自 MediaPipe FaceMesh 的标准 478 个关键点。

#### models/head_pose.py
使用 OpenCV 的 solvePnP 函数实现头部姿态估计。从 2D 关键点估计旋转和平移向量。

#### models/gaze_pose.py
实现视线估计管线：
- 从头部姿态计算 3D 人脸模型
- 归一化人脸方向以获得一致的输入
- 运行 ResNet18 模型预测视线角度
- 将角度转换为 3D 视线向量

#### models/utils.py
提供工具函数：
- 相机矩阵定义
- 3D 到 2D 点投影
- 可视化渲染
- 模型加载

## 实现方法

### 人脸检测

系统使用 MediaPipe FaceMesh，这是一个轻量级且高效的人脸检测解决方案，提供：
- 478 个 2D 面部关键点
- 实时性能
- 在不同光照条件下的鲁棒检测

### 头部姿态估计

头部姿态估计使用 Perspective-n-Point (PnP) 算法：

1. **3D 模型**: 使用预定义的 3D 关键点坐标
2. **2D 观测**: 从图像中检测到的关键点
3. **相机参数**: 内参矩阵和畸变系数
4. **算法**: `cv2.SOLVEPNP_ITERATIVE` 用于精确的姿态估计

输出是描述头部相对于相机的方向和位置的旋转向量和平移向量。

### 视线估计

视线估计管线包含几个步骤：

1. **3D 人脸模型构建**: 使用估计的头部姿态变换 3D 关键点
2. **人脸归一化**: 
   - 从眼睛和鼻子关键点计算人脸中心
   - 创建归一化旋转以使人脸与相机对齐
   - 应用透视变换创建归一化人脸图像
3. **模型推理**:
   - 将图像调整为 224x224
   - 转换 BGR 到 RGB
   - 应用 ImageNet 归一化
   - 运行 ResNet18 模型预测视线角度（俯仰角、偏航角）
4. **向量转换**: 将归一化的视线角度转换为 3D 向量
5. **反归一化**: 将视线向量转换回相机坐标系

### 可视化

系统提供全面的可视化：

| 元素 | 描述 | 颜色 |
|---------|-------------|-------|
| 边界框 | 人脸检测边界 | 绿色 |
| 关键点 | 478 个面部点 | 绿色 |
| 头部姿态轴 | 从鼻子出发的 X、Y、Z 轴 | 红色、绿色、蓝色 |
| 视线向量 | 视线方向 | 绿色 |

系统在 `models/utils.py` 中使用固定的相机内参：

```python
# 相机矩阵（640x480 分辨率）
camera_matrix = np.array([640., 0., 320., 0., 640., 240., 0., 0., 1.]).reshape(3, 3)

# 归一化相机矩阵（224x224 分辨率）
normalized_camera_matrix = np.array([960., 0., 112., 0., 960., 112., 0., 0., 1.]).reshape(3, 3)

# 畸变系数（无畸变）
dist_coefficients = np.array([0., 0., 0., 0., 0.]).reshape(-1, 1)
```

### 可视化选项

`models/utils.py` 中的 `render` 函数支持：
- `draw_face_bbox`: 绘制人脸边界框
- `draw_face_landmarks`: 绘制面部关键点
- `draw_head_pose`: 绘制头部姿态轴
- `draw_gaze_vector`: 绘制视线方向向量

## 模型详情

### 架构

视线估计模型使用 ResNet18，具有以下修改：
- 输入：224x224 RGB 图像
- 主干网络：ResNet18
- 输出：2 维向量（俯仰角、偏航角，单位为弧度）

### 训练

模型应在视线估计数据集上训练，包含：
- 归一化人脸图像
- 真实视线角度
- 适当的数据增强

### 预训练模型

预训练模型应放置在 `checkpoints/resnet18.pth`，结构如下：
